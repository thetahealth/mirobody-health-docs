## 什么是 Mirobody？

**Mirobody 把分散的健康数据，变成有据可查的答案。** 它读入化验单、穿戴设备数据、照片和基因文件，为每个值确定一个规范编码和单位，并让 agent 基于这份记录回答问题，标出每个数字来自哪份文件。引擎以 Apache 2.0 许可[开源](https://github.com/thetahealth/mirobody)，由 Theta Health 开发，也是其 Theta Wellness 应用所用的引擎。**Mirobody Cloud** 以托管 API 的形式提供同样的标准化与 agent 能力。
