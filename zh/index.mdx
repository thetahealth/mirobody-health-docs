## 什么是 Mirobody？

**Mirobody** 是一个健康数据引擎。它把任意来源的读数（化验单、可穿戴设备、基因检测、打印报告的手机照片）解析到规范编码，存成一份可以互相比较、可供 AI 推理的记录。

<NameOrigin />

引擎以 Apache 2.0 许可开源，仓库是 [thetahealth/mirobody](https://github.com/thetahealth/mirobody)。**Mirobody Cloud** 是它的托管形态：同一套标准化能力，通过兼容 OpenAI 的 `/v1` 接口提供，存储、模型与密钥由我们运维。

## 收集 · 转译 · 智能体

一条读数从进入系统到被引用，要经过三个阶段。每个阶段都留下记录，所以任何一个答案都能追溯到它出自的那一页。

## 选择 Mirobody 的运行方式

<RunModes />

| 选择依据 | Mirobody Cloud | 自部署引擎 |
| --- | --- | --- |
| 首个可用结果 | 创建 API 密钥，调用 `/v1` | 安装库或启动 Docker 栈 |
| 记录存储 | 由 Mirobody 运维，遵循 API 的留存设置 | 保存在你的 Postgres 与文件存储中 |
| 模型请求 | 由托管服务处理 | 发往你配置的模型服务商 |
| 部署与升级 | 由 Mirobody 运维 | 由你负责，步骤见[服务器部署指南](/zh/deployment/production) |
