中文 Cloud 快速开始默认使用中国区地址，英文版默认使用全球区；其他页面的示例可能使用其中任一区域。各区域使用独立主机和存储；运行示例前，请将 API 地址与密钥调整为同一区域，并使用已为账户开通的端点。

| 集群 | API base URL | 控制台 | 网页应用 | 状态 |
| --- | --- | --- | --- | --- |
| [🌐 全球](/zh/api-reference/regions/global) | `https://api.mirobody.ai/v1` | [platform.mirobody.ai](https://platform.mirobody.ai/) | [chat.mirobody.ai](https://chat.mirobody.ai/) | 已上线 |
| [🇨🇳 中国](/zh/api-reference/regions/china) | `https://api.mirobody.cn/v1` | [platform.mirobody.cn](https://platform.mirobody.cn/) | [chat.mirobody.cn](https://chat.mirobody.cn/) | 已上线 |
| 🇯🇵 日本 | — | — | — | 筹备中 |
| 🇪🇺 欧盟 | — | — | — | 筹备中 |

按数据处理位置选择集群：中国区域名在中国区环境处理数据，全球域名在全球环境处理数据。模型提供方与定价因区域不同，请从实际调用的集群读取 `GET /v1/models`。详见[隐私与合规](/zh/api-reference/compliance)。
