含义和单位一致的数据，才能用于跨来源比较。Mirobody 在本地完成名称解析与单位规范，
无需模型 API 密钥。

## 名称、编码与单位 {#名称编码与单位}

- 测量指标使用随包提供的 LOINC 词表。
- 用户记录的症状和诊断分别使用 ICPC-3 查询。
- 单位规范为 UCUM，只有维度兼容时才进行换算。
- 不同语言的别名可以对应同一概念；未知或有歧义的名称保留为未解析。

处理完整读数时，请保留原始单位，它可能影响编码选择。
名称相似，不代表医学含义一定相同。

## Python 示例 {#python-示例}

```python
from mirobody import resolve

result = resolve("hemoglobin")
print(result.loinc)  # 718-7
```

标准化完整读数时，还需提供原始数值与单位。
文档提取和库调用示例见[快速开始](/zh/quickstart)。

## 覆盖范围 {#覆盖范围}

随包词表覆盖选定的检验与临床观测，并非全部 LOINC 概念或设备自定义评分。
不兼容的单位不会被强行换算，未解析的名称也不会被替换为一个猜测编码。
当前词表标识可通过 `mirobody.BUNDLE_VERSION` 查看。

词表范围、许可和映射规则见[标准化技术参考](https://github.com/thetahealth/mirobody/blob/7775b50a55e17c98e1c02dfb93fb544dbccd1504/docs/standardization.md)。
