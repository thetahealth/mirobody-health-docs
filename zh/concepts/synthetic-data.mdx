[mirobody-gen](https://github.com/thetahealth/mirobody-gen) 为开发和评测生成合成健康记录，无需使用真实用户的文件。

## 可用数据

| 输入 | 对应流程 |
| --- | --- |
| 报告、表格和文档图片 | [文件上传](/zh/concepts/file-processing) |
| 手机健康库数据批次 | [设备字段对照](/zh/concepts/device-crosswalk) |
| 厂商格式的推送数据 | [设备集成](/zh/providers/using-providers) |
| 消费级基因型导出和 VCF | [基因数据](/zh/concepts/genetics) |

生成文件包含原始印刷值与标准化概念的预期结果，可以分别检查文字提取和编码是否正确。比较不同修改时，请固定生成器版本和随机种子。

## 开发中的用法

按生成器的[安装与构建说明](https://github.com/thetahealth/mirobody-gen)准备数据，再导入隔离的 Mirobody 环境，执行要验证的流程，并与预期结果对照。

Mirobody 的[模型评测资料](/zh/model-choice#评测资料)提供测试任务与结果入口。数据集定义、验证命令和隐私说明保留在生成器仓库中；Mirobody 正常运行时不会加载这些测试数据。
