## What is Mirobody?

**Mirobody** is a health data engine. It takes readings from any source — lab reports, wearables, genetic tests, phone photos of a printed report — resolves each one to a canonical code, and stores it as a comparable record an AI can reason over.

<NameOrigin />

The engine is open source under Apache 2.0, at [thetahealth/mirobody](https://github.com/thetahealth/mirobody). **Mirobody Cloud** is its hosted form: the same standardization behind an OpenAI-compatible `/v1` API, with storage, models and keys operated for you.

## Choose how you run Mirobody

<RunModes />

| Decision | Mirobody Cloud | Self-hosted engine |
| --- | --- | --- |
| First working result | Create an API key and call `/v1` | Install the library or start the Docker stack |
| Stored records | Operated by Mirobody, under the API's retention settings | In your Postgres and file storage |
| Model requests | Handled by the hosted service | Sent to the model provider you configure |
| Deployment and upgrades | Operated by Mirobody | Your responsibility; follow the [server guide](/en/deployment/production) |
