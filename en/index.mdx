## What is Mirobody?

**Mirobody turns scattered health data into answers you can trace.** It reads lab reports, wearable data, photos and genetic files, gives each value one standard code and unit, and lets an agent answer questions over the record while naming the file behind every number. The engine is [open source](https://github.com/thetahealth/mirobody) under Apache 2.0, built by Theta Health, and runs under its Theta Wellness app.

## Use it without running anything

[Theta](https://dr.thetahealth.ai/en/login?utm_source=mirobody&utm_medium=docs&utm_campaign=mirobody-to-theta&utm_content=docs_home), built on Mirobody, keeps your own records on the web and in its mobile app. To look first, the [live demo](https://chat.mirobody.ai/demo?ref=mirobody-docs&lang=en) answers over synthetic records, with nothing to sign up for.

The source, issues and releases are on [GitHub](https://github.com/thetahealth/mirobody). If Mirobody is useful to you, a star there helps others find it.
