## What is Mirobody?

**Mirobody turns scattered health data into answers you can trace.** It reads lab reports, wearable data, photos and genetic files, gives each value one standard code and unit, and lets an agent answer questions over the record while naming the file behind every number. The engine is [open source](https://github.com/thetahealth/mirobody) under Apache 2.0, built by Theta Health, and runs under its Theta Wellness app. **Mirobody Cloud** offers the same standardization and agent as a hosted API.
