[mirobody-gen](https://github.com/thetahealth/mirobody-gen) creates synthetic health records for development and evaluation. Use it to test ingestion and answers without using a real person's files.

## Available data

| Input | Integration |
| --- | --- |
| Reports, spreadsheets and document images | [File upload](/en/concepts/file-processing) |
| Phone health-store batches | [Device field mapping](/en/concepts/device-crosswalk) |
| Vendor-shaped payloads | [Device integrations](/en/providers/using-providers) |
| Consumer genotype exports and VCF | [Genetic data](/en/concepts/genetics) |

Generated files include expected printed values and standardized concepts, so extraction and coding can be checked separately. Use the same generator version and seed when comparing changes.

## Use in development

Start with the generator's [installation and build instructions](https://github.com/thetahealth/mirobody-gen). Load a generated dataset into an isolated Mirobody environment, exercise the workflow you are changing, and compare results with its expected data.

Mirobody's [model evaluations](/en/model-choice#evaluation-reference) link the benchmark workloads and results. The generator's own repository contains dataset definitions, validation commands and privacy documentation. Mirobody does not load these datasets during normal operation.
