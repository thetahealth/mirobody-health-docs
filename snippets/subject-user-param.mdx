<Note>
**The `user` field is the tenant-isolation key.** The backend maps `(your account, user)` to an internal **Subject**, and Subjects are fully isolated from one another — pass each end-user's stable id and no user ever sees another's data. Omit it and the call falls back to your account's default Subject. Subjects are invisible to the Mirobody web app and to other developers.

The value is normalized (trimmed + lowercased) before mapping, so `Alice` and `alice` resolve to the **same** Subject. Pass a stable, canonical id.
</Note>
