Before copying a `curl` example, choose your Cloud region. For authenticated calls, it must be **the same region as your key**. The examples below use `MIROBODY_API_BASE`:

```bash
export MIROBODY_API_BASE="https://api.mirobody.ai/v1"   # Global account
# export MIROBODY_API_BASE="https://api.mirobody.cn/v1" # China account: use this instead
```

For SDK examples with a literal Global URL, use the matching China URL when your account is in China. See [Regions](/en/api-reference/regions/overview).
