复制本页的 `curl` 示例前，先选择 Cloud 区域。需要认证的调用必须使用**与密钥同一区域**的地址。下方示例都使用 `MIROBODY_API_BASE`：

```bash
export MIROBODY_API_BASE="https://api.mirobody.cn/v1"  # 中国区账户
# export MIROBODY_API_BASE="https://api.mirobody.ai/v1" # 全球区账户：改用这一行
```

SDK 示例中如果写有全球区的完整地址，中国区账户须换成对应的中国区地址。参阅[区域](/zh/api-reference/regions/overview)。
