組み込みエージェントは、選択した人の健康記録について質問に答えます。Web クライアントの `/ask` ページ、またはチャット API から使えます。Claude Code、Codex、Cursor など外部のエージェントを使うには、[MCP](/ja/tools/mcp-integration) で接続してください。

## 利用できるツール

| タスク | 内容 |
| --- | --- |
| 健康記録を比較する | 測定値・服薬・遺伝子データを検索します。詳細は[健康データツール](/ja/tools/overview)を参照。 |
| 元の文書を読む | 本人がアップロードしたファイルと文書ライブラリを検索・読み取りします。 |
| 記録から計算する | `code_exec` が元のクエリ結果から計算します。クラウドのモデルではアプリ内の JavaScript、ローカルモデルではローカルのコンテナ内の Python を使います。[計算](/ja/tools/python-analysis)を参照。 |
| 医学資料を調べる | ローカルの医学資料インデックス、または有効化時は PubMed と ClinicalTrials.gov を検索します。これらのツールは本人の記録を検索しません。 |
| 質問を明確にする | 続ける前に、不足している情報を本人に尋ねます。 |

引用は、回答を記録済みの測定値・文書の一節・医学資料のいずれかに結び付けます。引用を開くと、回答の根拠を確認できます。

思考とツールの実行過程は作業パネルに表示され、最終的な回答は別に表示されます。長い会話はコンテキスト上限に近づくと自動的に要約され、要約中はパネルに表示されます。

**生成を停止**をクリックすると、ブラウザでの受信が終わります。サーバー側では生成が続いていることがあり、会話を更新すると、完了した回答が表示されることがあります。

## 設定 {#configuration}

**設定 › モデル**でモデルを選ぶか、[設定](/ja/configuration#the-model-key)の手順に従ってください。主なエージェント設定は次のとおりです。

| 設定項目 | 用途 |
| --- | --- |
| `DEFAULT_MODEL` | `MODELS` の中で既定にするエントリ。 |
| `ALLOWED_TOOLS` / `DISALLOWED_TOOLS` | 利用できるツールを制限します。許可リストが優先され、`code_exec` を拒否リストに入れると計算機能が無効になります。 |
| `AGENT_THINKING` | 要求する推論の強さ：`low`、`medium`、`high` のいずれか。既定は `medium` で、`off` も `medium` にフォールバックします。モデルエントリの `thinking_level` を有効にするとそちらが優先されます。OCR と抽出は別設定です。 |
| `KNOWLEDGE_INDEX` | `mirobody fetch knowledge` で作成したローカル医学資料インデックスのパス。 |
| `KNOWLEDGE_ONLINE` | PubMed と ClinicalTrials.gov の検索を有効にします。検索語はこれらのサービスに送信されます。 |

医学資料ツールは、ローカルまたはオンラインの情報源が使える場合にのみ表示されます。クラウドのモデルでは、計算に設定は要りません。ローカルモデルは、アプリが Docker デーモンに接続できれば Python、できなければ JavaScript で計算します。`mirobody doctor --probe` はモデルの能力を確認し、エンドポイントが思考を表示したかどうかを報告します。必要なときだけ思考するモデルはプローブの短い質問では思考しないことがあり、これは注意であって失敗ではありません。

## カスタムエージェント {#replacing-the-agent}

デプロイは `AGENT_DIRS`、またはインストール済みパッケージの `mirobody.agents` エントリポイントを通じて、組み込みエージェントを置き換えられます。harness を別のアプリケーションで再利用するには、`mirobody[agent]` をインストールしてください。連携の仕様とサンプルプラグインは <OssLink path="mirobody/agent/README.md" /> にあります。
